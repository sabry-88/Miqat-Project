استعادة كلمة المرور

خاصية استعادة كلمة المرور تتطلب ربط مزود خدمة الرسائل القصيرة (SMS) أو البريد الإلكتروني مع خادم النظام الخلفي.

ملاحظة تقنية حول الربط الخلفي
سيتم إتاحة استعادة الحسابات عبر إرسال رمز تحقق مؤقت (OTP) إلى رقم الموبايل أو رابط استعادة مشفر إلى البريد الإلكتروني فور تفعيل خادم المصادقة.
