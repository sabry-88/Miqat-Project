خيار محاكاة للواجهة فقط ولا يوفر حماية تشفير أو مصادقة فعلية.

تغيير أو إعادة تعيين كلمة المرور يتم حصرياً عبر مسؤول النظام (Admin).

تفضيلات العرض

تخصيص حجم الخط وكثافة المحتوى وتنسيق الجداول والتواريخ لحسابك.

الجلسات والأجهزة النشطة

عرض الأجهزة المتصلة بحسابك حالياً فقط. (سلوك محاكاة للواجهة).

أحدث نشاط الحساب الشخصي

أحدث الإجراءات المسجلة على حسابك الشخصي فقط.

لا توجد أنشطة مسجلة لهذا الحساب حتى الآن.

الصلاحيات الحالية

عرض صلاحيات حسابك الحالية؛ تعديل الصلاحيات يتطلب موافقة الإدارة.

طلبات تعديل الصلاحيات

أرسل طلباً لمراجعة أو ترقية صلاحية إلى الإدارة، وتابع حالة طلباتك المرسلة.

طلب تعديل صلاحية

لم ترسل أي طلبات تعديل صلاحية حتى الآن.

التواصل مع الإدارة

لطلبات تغيير كلمة المرور أو الصلاحيات الإدارية، يرجى التواصل عبر مكتب الإدارة الداخلي.

مكتب إدارة النظام — البوابة الداخلية للحسابات (لا توجد بيانات اتصال خارجية مضافة بعد)
